객체지향(OOP)이 뭘까요? 아주 간단해요!
우리가 만들고 싶은 학생 데이터의 모양을 나타내는 설계도(클래스)를 하나 만들어 두면, 이 설계도를 기반으로 실제로 살아 움직이는 학생 객체(인스턴스)를 찍어낼 수 있는 마법같은 프로그래밍 기법이에요!

클래스(Class) 붕어빵을 찍는 '쇠틀' 🐟
인스턴스(Instance) 갓 구워져 나온 '슈크림 붕어빵' 🍞
1단계. 설계도(클래스) 만들기 class_def.py
1 class Students:
2     def __init__(self, name, informatics, math):
3         self.name = name
4         self.informatics = informatics
5         self.math = math
6     def sum(self):
7         return self.informatics + self.math
8     def avg(self):
9         return self.sum() / 2
10     def string(self):
11         return '{}\t{}'.format(self.name, self.avg())
2단계. 학생 리스트(실제 객체들) 만들기 create_list.py
12 # 학생 리스트(객체) 생성
13 students = [
14     Students('김OO', 88, 90),
15     Students('정OO', 73, 65),
16     Students('한OO', 63, 77)
17 ]
3단계. 특정 학생의 데이터만 콕 집어 출력하기 print_one.py
18 # 특정 객체의 정보만 출력
19 print('김OO의 정보 성적')
20 print(students[0].informatics)
4단계. 전체 학생 성적 정렬하여 출력하기 print_all.py
21 print('이름', '평균', sep='\t')
22 for i in students:
23     print(i.string())
